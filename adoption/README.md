# Adoption

This directory is the **opt-in record of who uses the GFunnel Methodology and what they use it for.** It exists because GitHub's automatic analytics are aggregate and anonymous — the only reliable way to know *who* is applying the framework, and *which parts*, is for users to tell you. See [`../docs/usage-tracking.md`](../docs/usage-tracking.md) for the full picture.

## Who should register

- Businesses or teams running operations on the methodology.
- Products or services that embed it.
- **AI systems / agents** that load it as context or ship it inside a feature.
- Educators, coaches, or consultants applying it with clients.
- Researchers evaluating or extending it.

## How to register

Either:

- **Pull request** — add a row to [`registry.md`](registry.md) (preferred; it's a durable, attributable record), or
- **Issue** — open an *Application / Usage report* using the template in [`../.github/ISSUE_TEMPLATE`](../.github/ISSUE_TEMPLATE) and a maintainer will add you.

## What we ask for

Only what's useful and what you're comfortable sharing publicly: who you are, how you use it, and **which layers/algorithms** you rely on. That last field is what turns the registry into a real "what are they using" signal.

> Registration is voluntary and public. Don't include anything confidential. If you'd rather report privately, email the maintainer instead of opening a public entry.
