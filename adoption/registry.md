# Adoption Registry

An opt-in, public list of who uses the GFunnel Methodology and which parts. Add yourself via pull request (or an *Application / Usage report* issue). See [`README.md`](README.md) for guidance and [`../docs/usage-tracking.md`](../docs/usage-tracking.md) for why this exists.

## How to add a row

Copy the template row, fill it in, keep the table sorted by date added. Only share what's fine to make public.

| Name / Org | Type | How they use it | Layers / algorithms used | Version | Link | Date added |
| --- | --- | --- | --- | --- | --- | --- |
| _Your name or org_ | Business / Product / AI system / Educator / Researcher | _One line_ | _e.g. Layer V (BEAS), Master Meta-Algorithm_ | _e.g. v5.1_ | _optional URL_ | _YYYY-MM-DD_ |
