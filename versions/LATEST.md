## If you only load one thing

Load **v5.1** — it is explicitly self-contained ("every concept needed to operate the framework is defined inside this document; no prior version is required"). v5.2 and v5.3 refine and extend it; they do not stand alone.

## What "latest" does *not* mean

- It does **not** mean v5.3 replaces v5.1. v5.3 is a small meta-tier addition that *depends on* the earlier text.
- It does **not** mean earlier versions are deprecated. Each version is immutable once released; corrections happen in a new version, per the [Iteration Protocol](../CONTRIBUTING.md).
