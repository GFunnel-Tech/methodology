## Canon says

v5.1 Layer I.C, Domain 3:

- *Learning Algorithm:* "New stimulus → pattern recognition → schema comparison → schema update if novel → higher baseline."
- *Trauma Algorithm:* "Normal: stimulus → PROCESS → integrate → baseline shift. Trauma: stimulus magnitude exceeds current processing capacity → processing arrests → input stored as unresolved active variable. Trauma is not identity. It is an incomplete processing cycle."
- *Belief Causal Loop:* "Repeated inputs + emotional charge → pattern → belief → perceptual filter → self-confirming evidence loop."
- *Variable — held open:* "The hard problem of consciousness ... The framework tightens toward Mentalism: per Layer I.F, an emergent consciousness cannot perform the meta-cosmological observation function the framework requires; only foundational consciousness can. Range narrows substantially."
- Domain 3 Algorithm step 2: "every dysfunction has a belief filter producing self-confirming evidence"; step 5: "the window of tolerance. Expand it through gradual exposure."

**Split.** *Factual core:* new information is compared with existing schemas and incorporated; trauma memories are processed differently and persistence of symptoms relates to incomplete processing; beliefs bias the evidence people seek and accept; the hard problem is unsolved. *Framework mapping:* Kingdom levels (arousal / belief / identity), Fibonacci baseline, Cause-and-Effect reading, and the narrowing of the hard problem toward Mentalism.

## Scientific Inquiry run
1. Question (precise): Do the learning, trauma, and belief sequences in Domain 3 match the primary literature, and is the DETECT → PROCESS → RESPOND mapping forced or fitted?
2. What an answer must look like: experimental evidence that schemas govern incorporation of new information; a tested model of trauma persistence; evidence on who develops persistent symptoms; a named observation that would count as non-mapping.
3. Falsifiability condition: Learning: fails if prior schemas do not change how new information is incorporated. Trauma: fails if symptom persistence is unrelated to how the memory is processed, or if magnitude alone predicts outcome. Mapping: canon names no failing observation.
4. Variables: measurable / bounded / held open: measurable: memory consolidation, PTSD symptom persistence, resilience trajectories. Bounded: the trauma model (supported, not proven). Held open: the hard problem; "processing capacity" (no independent measure; inferred from the outcome).
5. Test designed: Fetch a primary schema-consolidation experiment; the leading cognitive model of PTSD persistence; a review of resilience; the source statement of the hard problem.
6. Data (unfiltered): Tse et al. 2007: schemas causally speed consolidation of new associations (rat). Ehlers & Clark 2000: persistence tied to negative appraisals and poorly elaborated, poorly contextualized trauma memory; many people recover; support preliminary. Bonanno 2004: resilience is common and is a distinct trajectory. Chalmers: the problem of experience is the hard problem. No primary confirmation-bias or window-of-tolerance source reached.
7. Variable Principle applied: Learning sequence: consistent with measurement. Trauma as "incomplete processing": consistent with one leading model (poorly elaborated memory), a live hypothesis, not a settled fact. "Stimulus magnitude exceeds current processing capacity" cannot be tested as written: capacity has no measure independent of the outcome, so it is inferred after the fact (circular). The high rate of resilience shows exposure magnitude alone does not determine outcome. Belief loop: held open (not sourced this run). Hard problem: held open. Canon's "Range narrows substantially" toward Mentalism rests on the framework's own Layer I.F argument, not on a measurement; reality does not narrow this range.
8. Model update (Capsule: what the failed parts contribute): Trauma Algorithm should name "processing capacity" as a variable with no independent measure, and add the resilience trajectory (exposure → no persistent arrest). The hard-problem variable should revert to fully open for the audit's purposes; the narrowing is internal to the framework.
9. Documented: This file.
10. Next baseline: Learning: accounted. Trauma: live hypothesis (model-supported). Belief loop, window of tolerance: held open pending sources. Hard problem: proven-open (canon), narrowing not forced.

## Forcing Test
- Test A (Ground): Learning and trauma sequences have measured or model-level ground. The hard-problem narrowing has none outside the framework.
- Test B (Uniqueness): The trauma account is one of several models (the fetched model is cognitive; others exist). "Incomplete processing cycle" is not the only candidate.
- Test C (Direction): Learning sequence: observation → schema model, correct direction. Trauma: "stimulus magnitude exceeds current processing capacity" runs from outcome back to capacity (capacity is read off the result).
- Test D (Falsifiability): Learning: falsifiable and survives. Trauma: falsifiable only if processing capacity is measured before exposure; canon does not specify how. Mapping: no failing observation named.
- **Outcome:** live-hypothesis for the factual core (falsifier: prospective studies in which measured pre-exposure processing capacity fails to predict persistence, or in which persistence is unrelated to memory elaboration). Mapping: stipulation.

## Anti-Operation (the gap this opens)

- "Processing capacity" is used as a measured quantity throughout Domain 3 and its Algorithm; it has no measure. Open variable.
- Resilience (exposure without persistent arrest) is a common, distinct trajectory that the Trauma Algorithm does not name.
- The Belief Causal Loop and "window of tolerance" still need primary sourcing (next run).

## Narrative stripped (if any)

- **Kingdom levels (arousal = First, belief = Second, identity = Third)**: a classification choice; reality neither forces nor contradicts it.
- **"The framework tightens toward Mentalism ... Range narrows substantially"**: the narrowing uses the framework's own requirement ("the meta-cosmological observation function the framework requires"), not a measurement. Reality does not force it; for audit purposes the variable stays fully open.
- **Mapping verdict: stipulation, with good fit.** Stimulus → processing → response is the standard description in cognitive psychology, so the mapping fits easily. That is also why it does not test anything: the same three slots describe any input-output system. Canon names no observation that would count as failure to map.
