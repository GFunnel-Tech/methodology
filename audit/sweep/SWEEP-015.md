Shannon's formula quantifies exactly what the Variable Principle describes qualitatively." Core Axiom Connection: "**Data in → Data processing → Data out. ## Scientific Inquiry run

1. Question (precise): Does a canonical item hold operon logic — repressor, inducer, measured cooperativity — and does DETECT → PROCESS → RESPOND fit a measured two-input regulatory function?
2. What an answer must look like: a canonical item that represents multi-input regulation, plus measured repression ratios and the measured shape of the input function.
3. Falsifiability condition: the "data in / processing / data out" claim fails as a *sufficient* description if the measured regulatory output is not a function of one input at a time but of a joint surface with internal structure the three-step form cannot carry.
4. Variables: measurable / bounded / held open: Measurable: repression ratios per operator configuration; the shape of the two-input function. Bounded: cooperativity is bounded by the tetramer's loop geometry (removal of both auxiliary operators costs more than the sum of removing each). Held open: a single cooperativity exponent — not stated by the fetched sources.
5. Test designed: fetch the classic operator-deletion series (cooperativity) and the two-input mapping of the lac input function; ask whether either is representable as one DPR pass.
6. Data (unfiltered): table above. Repression is non-additive: 2-3 fold each, greater than 50-fold together. The input function has four plateaus and four thresholds over two inducers.
7. Variable Principle applied: canon's "data in, processing, data out" is true but empty at this resolution: it does not distinguish a single-threshold switch from a four-threshold two-input surface, and it names no cooperativity. A cooperativity number must not be filled in from assumption; held open above.
8. Model update (Capsule: what the failed parts contribute): the informative measured fact is that the *processing* is in the DNA geometry (loop formation), not in a molecule that reads and decides. The framework's PROCESS operation, defined as "the system acts on input according to its organizational architecture", is unexpectedly literal here: the architecture is physical looping. That is the strongest form of the canonical mapping available, and it is a derivation, not canon.
9. Documented: this file. Correspondence: one scale down, LacI-operator binding equilibria; one scale up, a promoter integrating several transcription factors as a logic gate — canon has no item for logic gates.
10. Next baseline: an audit item for multi-input regulation; a PRED candidate on non-additivity (predict the two-operator deletion cost from the single-deletion costs, which the measured values violate).

## Forcing Test

- Test A (Ground): Grounded on the reality side; canon's item is a general statement with no measured content at this scale.
- Test B (Uniqueness): Not unique. Any input-output system satisfies "data in, processing, data out"; the form excludes nothing, so it cannot be uniquely forced by these measurements.
- Test C (Direction): Measurement points toward multi-input non-additive computation, a structure the three-step form does not encode.
- Test D (Falsifiability): "Data in → processing → data out" as stated has no falsifier at this scale, which is itself the finding.
- **Outcome:** `stipulation`. DPR mapping is **after-the-fact**: DETECT = inducer binding, PROCESS = loop formation and occupancy, RESPOND = transcription rate — but the cut points are chosen by the auditor, and the measured object (a two-input surface) has no three-part structure.

## Anti-Operation (the gap this opens)

Canon says the algorithm has "zero exceptions" but supplies no test that any specific system could fail. The lac input function shows what a real test needs: a *predicted* number of thresholds. The gap: the framework must state, for some system, how many thresholds its loop implies — otherwise the loop is unfalsifiable at this scale (compare Layer ◇, which requires each claim to name its falsifier).

## Narrative stripped (if any)

Removed: "Shannon's formula quantifies exactly what the Variable Principle describes qualitatively." Shannon entropy is a measure over a known distribution; a held-open variable in the framework's sense has no distribution. No measurement fetched here forces the identification, and the word "exactly" is not supported.
