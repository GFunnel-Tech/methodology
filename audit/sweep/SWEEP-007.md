## Canon says

Nothing. The canonical corpus contains no item for pili, surface attachment, adhesion, surface sensing, or any form of motility. Searched across `versions/` and `framework/` for `pili`, `motility`, `adhesio`, `twitching`, `biofilm`: zero hits.

The canonical claim under test is therefore Layer I.C's coverage claim, v5.1: "*Correspondence at Full Scale — Ten Domains, One Base Code, Zero Exceptions.*" and, from `framework/domains.md`: "If Correspondence is law (not analogy), the base code `DETECT → PROCESS → RESPOND` must be demonstrable in *every* known process domain without exception. Each domain is not an illustration; it is a **test**. Per the Variable Principle: if any domain resists the mapping cleanly, it becomes a *named variable*, not a disproof."

Reference organisms: this record departs from E. coli K-12, which does not perform type IV pilus twitching motility. The measured systems are *Neisseria gonorrhoeae* (single-pilus force) and *Pseudomonas aeruginosa* (pilus dynamics and surface sensing) — the two best-measured twitching systems.

**Split.** *Factual core:* there is a whole class of bacterial sensing-and-locomotion machinery. *Framework mapping:* none exists to grade; the mapping question is whether canon's coverage claim survives an unnamed mechanism.

## Scientific Inquiry run
1. Question (precise): Is there any canonical item that holds type IV pilus twitching motility and surface adhesion, and if not, does the measured mechanism exhibit a DETECT → PROCESS → RESPOND decomposition at distinguishable boundaries?
2. What an answer must look like: a grep result over the canonical corpus; and, for the mechanism, a named molecule and event per operation with a statement of separability.
3. Falsifiability condition: canon's "zero exceptions" coverage claim is exceeded, in the weak sense, if a measured process domain member has no canonical holder. It is *resisted* in the strong sense if the mechanism's operations cannot be separated into three.
4. Variables: measurable / bounded / held open: measurable — stall force, velocity-force break point, motor count per event, ATP dependence, timing of engagement, tension-dependent adhesion. Bounded — ATP per subunit (derived). Held open — whether this belongs in Domain 9 or in a domain canon does not name.
5. Test designed: grep the corpus; fetch the single-pilus force measurement and the four-dimensional pilus-dynamics measurement; assign DPR.
6. Data (unfiltered): a single pilus driven by a single PilT complex stalls at 110 ± 30 pN, with velocity constant below 40 pN. ATP depletion slows retraction but does not change stall force. PilT engages almost only on surface contact. Tension makes the adhesion stronger, not weaker. PilU matters only under high friction. Canon names none of this.
7. Variable Principle applied: **Measured** — forces, timing, tension-dependence. **Structurally derived** — ATP per subunit. **Held open** — domain placement. The DPR mapping: DETECT = surface contact, sensed by the pilus itself becoming loaded; PROCESS = engagement of the PilT ATPase; RESPOND = retraction and cell displacement. The DETECT boundary is measurable in time (engagement follows contact "very rapidly and almost only" then) — that is a genuine, dated boundary, not a relabel. But two features resist the decomposition: (a) the pilus is simultaneously the sensor, the transmission and the actuator, so the three operations are not three parts; (b) tension-reinforced adhesion is a *mechanical* positive feedback with no informational step at all — the harder the cell pulls, the better the grip. There is no molecule to call PROCESS in that loop. A control loop with no processing step is outside canon's algorithm as written.
8. Model update (Capsule: what the failed parts contribute): the framework needs a named variable for mechanically closed loops — loops whose feedback is carried by force rather than by a signal. Per the Variable Principle this is held open and named, not resolved: **Variable: does the base code require an informational PROCESS step, or does a mechanical feedback path satisfy it?** Canon does not say. The failed attempt to find a PROCESS molecule is what produces the variable.
9. Documented: this file.
10. Next baseline: unmapped and named. The open variable (mechanical versus informational processing) carries forward to SWEEP-008, where the same question recurs in a channel.

## Forcing Test
- Test A (Ground): grounded. Two independent groups, two techniques (optical-tweezers force spectroscopy; interferometric scattering microscopy), fetched this run.
- Test B (Uniqueness): not unique. For the contact-sensing arm, DPR can be assigned with defensible boundaries. For the tension-reinforced adhesion arm, no assignment with three operations is available, and at least one assignment with two is.
- Test C (Direction): canon runs signal → processing → action. The tension-reinforcement path runs action → force → more action, with no signal. The directions are not the same kind of arrow.
- Test D (Falsifiability): the weak condition (no canonical holder) is met. The strong condition (operations cannot be separated into three) is met for one of the two measured arms and not the other. Recorded as a split result.
- **Outcome:** `stipulation`. Canon's "zero exceptions" is a presentation claim here, not a forced result: the exception is not a contradiction, it is an absence, and per the Variable Principle it becomes a named variable. `unmapped`, diagnosis `not-reached`, `canon_ref: none`.

## Anti-Operation (the gap this opens)

- The named variable above: whether a purely mechanical feedback loop instantiates the base code. Until it is settled, every claim that the base code has zero exceptions is untested against mechanics.
- One machine as sensor, transmission and actuator. The framework's organ-level vocabulary (Layer I.F's "intake organ", Layer V's departments) presumes separable parts. There is no canonical treatment of a system whose parts are the same part.
- Stall force does not change when ATP is depleted, but rate does. Canon has no distinction between the force a system can exert and the rate at which it can exert it; Layer III's Process Density conflates them.
