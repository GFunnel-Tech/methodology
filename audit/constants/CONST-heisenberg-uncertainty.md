## Scientific Inquiry run
1. Question (precise): Does the law, as canon states it, match its measured form and domain of validity?
2. What an answer must look like: Which relation Δx·Δp ≥ ℏ/2 denotes, and whether measurement supports it.
3. Falsifiability condition: A state with σₓσₚ < ℏ/2.
4. Variables: measurable / bounded / held open: Derived: Kennard bound (theorem of QM). Measured: error–disturbance version violated. Held open: none.
5. Test designed: Literature fetch.
6. Data (unfiltered): With Δ = standard deviation of the state (Kennard), the bound is a theorem and holds. With Δ = measurement error × disturbance (Heisenberg's 1927 microscope reading), it is violated experimentally (Erhart 2012); Ozawa's relation replaces it. Canon does not say which Δ it means.
7. Variable Principle applied: No variable filled; canon's Δ is ambiguous and is stated as such.
8. Model update (Capsule: what the failed parts contribute): Formula correct under the standard-deviation reading; the error–disturbance reading is experimentally false.
9. Documented: this file.
10. Next baseline: Re-run on the next PDG edition (2026 Review of Particle Physics) or on the named experiment's next result (Phase 9).

## Anti-Operation (the gap this opens)
Canon does not define Δ. Readers taking it as measurement disturbance would hold a relation that experiment has violated. Definition is the gap.
