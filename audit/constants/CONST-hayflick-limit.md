The ~50 figure has been reproduced since 1961 (Shay & Wright call it the 'Hayflick limit' after decades of follow-up), hence `measured-reproduced`. The 1961/1965 abstracts are not online; the value is taken from Hayflick's 1985 abstract.

## Scientific Inquiry run

1. Question (precise): Do normal human cells stop after ~50 divisions, and is the end state senescence?
2. What an answer must look like: Population-doubling counts and the observed cell fate.
3. Falsifiability condition: A reproduced count far from 50 for the same cell type, or apoptosis as the end state.
4. Variables: measurable / bounded / held open: Measurable: population doublings. Bounded: ~50 for fetal fibroblasts. Held open: uniformity across cell types and donors.
5. Test designed: Compare canon with Hayflick's reports and later tests.
6. Data (unfiltered): ~50 for fetal strains (Hayflick 1985). End state is senescence (Shay & Wright 2000); senescent fibroblasts resist apoptosis (Wang 1995). Uniformity is contested (Rubin 2002).
7. Variable Principle applied: The value holds; uniformity is held open.
8. Model update (Capsule: what the failed parts contribute): Keep the Statement. The Role's 'apoptosis trigger' is factually wrong: the limit ends in senescence, not apoptosis.
9. Documented: This file.
10. Next baseline: Integrated; Role error reported.

## Forcing Test

- Test A (Ground): Grounded in reproduced measurement.
- Test B (Uniqueness): One value (~50) for the reference cell strains.
- Test C (Direction): n/a.
- Test D (Falsifiability): Falsifiable; passed.
- **Outcome:** `forced-fill` for ~50 doublings to senescence in fetal fibroblasts.

## Anti-Operation (the gap this opens)

The limit is measured in culture; Hayflick 1985 notes it is never reached in vivo. How it maps to organismal ageing is held open, and the registry does not say so.

## Narrative stripped

Removed: 'Built-in cellular apoptosis trigger' and 'complies with Step 07 (Repetition)'. The first is a factual error (senescence ≠ apoptosis; senescent fibroblasts resist apoptosis). The Step 07 mapping is interpretation that reality does not force.
