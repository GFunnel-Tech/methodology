Diminishing returns beyond some input level is well supported. A linear-plateau response has *constant* marginal returns up to the plateau, then zero, so 'each additional unit produces less' is not literally true everywhere.

## Scientific Inquiry run

1. Question (precise): Does output per added input fall?
2. What an answer must look like: Dose–response curves.
3. Falsifiability condition: Responses that are linear or convex over the relevant range.
4. Variables: measurable / bounded / held open: Measurable: yield vs input. Bounded: concave or plateau beyond a threshold. Held open: none.
5. Test designed: Use agronomic N-response data.

## Anti-Operation (the gap this opens)

Canon's Role says 'the dynamic middle is where marginal return is maximized'. In standard economics the operating optimum is where marginal return equals marginal cost, not where marginal return peaks. The optimisation criterion the framework intends is open.
