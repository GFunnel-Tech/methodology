## Reality shows

Lindenfors et al. conclude that 'specifying any one number is futile' and that 'a cognitive limit on human group size cannot be derived in this manner'. It is one re-analysis, so it is graded `measured-single` and cannot drive `adjusted`.

## Scientific Inquiry run

1. Question (precise): Is there a measured cognitive limit of ~150 relationships?
2. What an answer must look like: An estimate with a confidence interval that excludes much else.
3. Falsifiability condition: Re-analysis whose intervals include values far from 150 or none.
4. Variables: measurable / bounded / held open: Measurable: group size, neocortex ratio. Bounded: nothing narrow. Held open: whether a cognitive limit exists.
5. Test designed: Compare the original derivation with the 2021 re-analysis.
6. Data (unfiltered): Re-analysis: 69–109 (CI 4–520) and 16–42 (CI 2–336).
7. Variable Principle applied: The value is held open; canon's '~150' and 'cognitive limit' fill it.
8. Model update (Capsule: what the failed parts contribute): Re-word: '~150 (Dunbar's extrapolation; contested, not reproduced)'.
9. Documented: This file.
10. Next baseline: Open until an independent replication resolves it.

## Forcing Test

- Test A (Ground): Weak ground: a regression extrapolation.
- Test B (Uniqueness): Not unique: re-analysis gives very different numbers.
- Test C (Direction): n/a.
- Test D (Falsifiability): Falsifier: phylogenetic re-estimates with narrow intervals far from 150.
- **Outcome:** `live-hypothesis`.

## Anti-Operation (the gap this opens)

Canon's Domain 3 and Second-Kingdom 'infrastructure threshold' reasoning rests on this number. If the limit is not real, what sets the scale at which institutions become necessary is an open variable.

## Narrative stripped

Removed: 'Beyond it requires Second Kingdom infrastructure (institutions).' This builds on a limit that is not established. Reality does not force it.
