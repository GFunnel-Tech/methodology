## Scientific Inquiry run

1. Question (precise): Does network value scale as n²?
2. What an answer must look like: A fit of a value proxy against n.
3. Falsifiability condition: Better fits to n log n or other forms.
4. Variables: measurable / bounded / held open: Measurable: user counts, revenue proxies. Bounded: nothing. Held open: what 'value' is.
5. Test designed: Compare the n² claim with the n log n critique.
6. Data (unfiltered): One study reports n² fits; critics argue n log n.
7. Variable Principle applied: Value is a proxy-dependent variable; canon fills it with n².
8. Model update (Capsule: what the failed parts contribute): Label as contested.
9. Documented: This file.
10. Next baseline: Open.

## Anti-Operation (the gap this opens)

Canon does not define 'value'. Without a measured quantity, the law cannot be tested; that definition is the open variable.

## Narrative stripped

Removed: 'Per Vibration: more nodes = more potential resonance pairs.' n² counts possible pairs; calling them 'resonance' pairs is interpretation. Reality does not force it.
