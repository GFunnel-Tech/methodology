## Scientific Inquiry run
1. Question (precise): Does the law, as canon states it, match its measured form and domain of validity?
2. What an answer must look like: Measured tests of Newtonian inertia; the domain where it holds.
3. Falsifiability condition: An unforced body in an inertial frame accelerating.
4. Variables: measurable / bounded / held open: Measured: F = ma at tiny accelerations; inertial = gravitational mass. Held open: none within the domain.
5. Test designed: Literature fetch.
6. Data (unfiltered): Consistent. Domain: inertial frames; in GR 'unacted-upon' motion is geodesic motion (gravity is not a force), of which the first law is the flat-space, low-speed limit. Canon omits 'in an inertial frame'.
7. Variable Principle applied: No variable open.
8. Model update (Capsule: what the failed parts contribute): Law survives; add the inertial-frame condition.
9. Documented: this file.
