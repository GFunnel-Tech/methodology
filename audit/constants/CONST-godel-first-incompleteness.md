## Anti-Operation (the gap this opens)

The theorem applies to formal systems. Whether the framework is, or can be written as, a formal system is held open; until it is, the theorem cannot be applied to it except by analogy.

## Narrative stripped

Removed: 'the framework's structural acknowledgment of irreducible variables'. The framework is a prose document, not an effectively axiomatized formal system containing arithmetic, so Gödel's theorem does not apply to it as stated. The mapping is analogy; reality does not force it.
