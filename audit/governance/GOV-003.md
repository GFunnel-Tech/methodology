## Scientific Inquiry run
1. Question (precise): Is a step that diagnoses *why* an observation is missing from, or conflicts with, the log forced by canon, or an optional addition?
2. What an answer must look like: Forced if classifying an absence without a diagnosis would fill a variable with assumption; optional if canon already covers it.
3. Falsifiability condition: Show a case where the Forcing Test classifies a missing item correctly without knowing why it is missing.
4. Variables: measurable / bounded / held open: Measurable: canon texts. Stipulated: the specific four categories (not-reached / reached-conflicting / unverified / beyond-depth).
5. Test designed: Take one absence and run it through the Forcing Test with and without a diagnosis.
6. Data (unfiltered): Example: reality shows X; canon lacks X. If X is unverified, the right action is `open` (substrate item 8); if not-reached, extend the log; if reached-conflicting, re-form an entry; if beyond-depth, hold it back (concentration). Four causes, four different actions. Without the diagnosis, choosing an action means assuming the cause — which the Variable Principle forbids. Canon already runs this step one scale down: I.F step 3 diagnoses *which observation levels are absent* before acting.
7. Variable Principle applied: The cause of absence is itself a variable; the diagnosis names it instead of assuming it.
8. Model update (Capsule: what the failed parts contribute): The falsifier did not fire; no information lost.
9. Documented: This file; SCHEMA.md §1.4; FINDINGS F-005.
