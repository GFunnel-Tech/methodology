## Scientific Inquiry run

1. Question (precise): Is there a measured quantity "organized, interdependent complexity per unit volume", and does a cell have its highest known value?
2. What an answer must look like: A defined metric with units, values for a cell and for candidate non-biological systems, with uncertainties.
3. Falsifiability condition: Canon's: a non-biological system exceeding a cell on the metric. It cannot fire until the metric is defined.
4. Variables: measurable / bounded / held open: Measurable: molecular counts per volume (e.g. proteins per µm³). Held open: the composite metric itself; values for any non-biological system.
5. Test designed: Look for a primary-source definition and measurement of the metric; failing that, record the nearest measured proxy.
6. Data (unfiltered): Proxies such as proteins per µm³ exist for cells. No source defines or measures "organized interdependent complexity". Canon's own ◈ note concedes the definition may need refinement.
7. Variable Principle applied: Held open. The claim "biological systems highest" and the evidence "no known counterexample" are not filled: with no metric, absence of counterexample is not evidence.
8. Model update (Capsule: what the failed parts contribute): BLOCKED at the metric. The blocker is the location of the work: define the measure (e.g. component count × interaction count per volume, with a stated counting rule) so it can be computed for a cell, a chip, and a star.
9. Documented: This file. Finding: v5.1 Governing Epistemology and framework/registers.md call process density "empirically settled"; the Falsifiability Register and Doc Variable Registry call it "Open". The settled label exceeds the evidence.
10. Next baseline: A canonical metric definition. Re-review 2027-09-24.

## Forcing Test

- Test A (Ground): No measured ground for the metric; proxies only.
- Test B (Uniqueness): Many metrics could be chosen; the ranking of cell vs. other systems depends on the choice. Not unique.
- Test C (Direction): None.
- Test D (Falsifiability): Falsifier stated but not operational (the quantity is undefined, so it cannot be exceeded).
- **Outcome:** live-hypothesis. Its "Empirically settled" label elsewhere in canon is unsupported.

## Anti-Operation (the gap this opens)

Once a metric is defined, the ranking can change with the counting rule (what counts as a component, as an interaction, at what scale). The gap: canon must state the counting rule before the claim can be tested, and must accept that the rule, not the systems, may decide the result.
