## Scientific Inquiry run

1. Question (precise): Is there a measured phenomenon that "operates by fundamentally different laws at different scales with no self-similarity", and can canon's falsifier be applied to one?
2. What an answer must look like: A named measured system whose governing behaviour changes with scale, plus a canonical criterion stating whether that change is "surface behavior" or "principle".
3. Falsifiability condition: Canon's own. It fires only if a scale change can be classified as a change of principle. Canon supplies no classification rule.
4. Variables: measurable / bounded / held open: Measurable: scale-dependent couplings (αs, α). Held open: whether any scale change counts as a violation of Correspondence.
5. Test designed: Take the best-measured case of scale-dependent behaviour (running of αs) and try to apply the falsifier.
6. Data (unfiltered): One theory (QCD) holds at all tested scales, but its behaviour differs sharply with scale: weakly coupled above ~100 GeV, strongly coupled at or below 1 GeV, where the high-energy calculation method (perturbation theory) fails. Canon can read this either as "same law" (Correspondence holds) or as "a method solved at one scale is not solved at another" (Axiom 10's strong form fails). Canon provides no rule to decide.
7. Variable Principle applied: The variable stays open, as canon holds it. The measurement does not fill it.
8. Model update (Capsule: what the failed parts contribute): The test cannot be completed as written; the blocker is the undefined boundary between "principle" and "surface behavior". That boundary is where the work is.
9. Documented: This file. Correspondence (one scale up): CLAIM-007 (universal algorithm) has the same non-operational falsifier; one scale down: CLAIM-014 condition (4) repeats this falsifier and says it has not been observed.
10. Next baseline: A canonical definition of "principle" precise enough to classify the αs case. Re-review 2027-09-24.

## Forcing Test

- Test A (Ground): Scale dependence of physical behaviour is measured (αs, α). Correspondence of "principles" has no measured ground.
- Test B (Uniqueness): Both readings (holds / violated) survive; none is eliminated.
- Test C (Direction): None given by measurement.
- Test D (Falsifiability): Falsifier present but not operational: any scale difference can be assigned to "surface behavior".
- **Outcome:** live-hypothesis; the falsifier needs operationalizing before it can fire. Not resolved.

## Anti-Operation (the gap this opens)

Axiom 10 ("Solve it at any scale and you have solved it at every scale") is stronger than the register row. Measured running couplings are a case where a working solution method at one scale fails at another. Canon should say whether Axiom 10 means the principle or the method; the two readings have different truth values against measurement.

- "Hermetic position": a doctrine, not a measurement.
