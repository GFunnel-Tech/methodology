## Scientific Inquiry run
1. Question (precise): Do dedicated circuits assign valence to signals before deliberate evaluation?
2. What an answer must look like: Neural recordings showing value (valence) coding linked to learning.
3. Falsifiability condition: Fails if valence coding appears only downstream of deliberate cortical evaluation.
4. Variables: measurable / bounded / held open: Measurable: amygdala valence coding. Held open: relation between valence circuits and felt emotion; 'pre-rational' timing in humans.
5. Test designed: Retrieve recordings of amygdala value coding and a review on emotion circuits.
6. Data (unfiltered): Paton et al. 2006: amygdala neurons code positive and negative value; LeDoux 2012 separates survival circuits from emotional feelings.
7. Variable Principle applied: Felt emotion vs valence coding held open.
8. Model update (Capsule: what the failed parts contribute): Valence evaluation by subcortical circuits accounted; 'emotion' as felt experience is a different variable.
9. Documented: This file.
10. Next baseline: Valence coding measured; its identity with emotion not forced.

## Forcing Test
- Test A (Ground): Measured (valence coding).
- Test B (Uniqueness): Not unique: 'emotion' may name valence coding or felt experience — canon conflates the two.
- Test C (Direction): Consistent.
- Test D (Falsifiability): Falsifier in step 3.
- **Outcome:** live-hypothesis (identification of emotion with pre-rational valence evaluation).

## Anti-Operation (the gap this opens)
Is 'emotion' the valence computation or the felt state? The fetched review treats them as distinct; canon's row does not say which it means. Whether 'limbic' is a valid anatomical grouping was not tested in this run.
