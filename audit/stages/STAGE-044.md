## Scientific Inquiry run
1. Question (precise): Do the institutional characteristics of complex societies co-vary (operate in coordination)?
2. What an answer must look like: Cross-cultural quantitative data on institutional features.
3. Falsifiability condition: Fails if governance, economy, information systems, etc. varied independently across societies.
4. Variables: measurable / bounded / held open: Measurable: Seshat variables. Held open: causal direction among institutions.
5. Test designed: Retrieve the Seshat PCA result.
6. Data (unfiltered): One principal component explains ~3/4 of variation across 9 characteristics in 414 societies.
7. Variable Principle applied: Causal direction held open.
8. Model update (Capsule: what the failed parts contribute): Core integrated: institutional features co-vary strongly.
9. Documented: This file.
10. Next baseline: Co-evolving institutional complexity (Seshat).
