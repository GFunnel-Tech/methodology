## Scientific Inquiry run
1. Question (precise): Does cortex build predictive internal models that shape perception?
2. What an answer must look like: Neural evidence that feedback carries predictions and feedforward carries errors, or equivalent.
3. Falsifiability condition: Fails if cortical responses show no dependence on expectation/context beyond feedforward input.
4. Variables: measurable / bounded / held open: Measurable: extra-classical receptive-field effects. Derived: predictive-coding account of them. Held open: predictive processing as the general cortical principle.
5. Test designed: Retrieve the founding predictive-coding model paper.
6. Data (unfiltered): Rao & Ballard 1999: a predictive-coding network reproduces extra-classical effects. This is a model that explains measured effects, not a direct measurement of predictions.
7. Variable Principle applied: General predictive-processing theory held open.
8. Model update (Capsule: what the failed parts contribute): Cognition as model-building: consistent; predictive coding: live hypothesis.
9. Documented: This file.
10. Next baseline: Internal models accounted; predictive coding as mechanism live.

## Forcing Test
- Test A (Ground): Model evidence; indirect.
- Test B (Uniqueness): Not unique: other accounts (e.g. purely feedforward normalization) explain some of the same effects.
- Test C (Direction): Consistent.
- Test D (Falsifiability): Falsifier: absence of prediction-error signals where the model requires them.
- **Outcome:** live-hypothesis.
