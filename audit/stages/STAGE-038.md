**Factual core (graded):** beings form intentions and initiate actions that set causes, beyond reactive responses.

**Framework mapping (stripped):** First → Second → Third Kingdom progression.

## Scientific Inquiry run
1. Question (precise): Do conscious intentions originate (set the cause of) voluntary actions?
2. What an answer must look like: Timing of neural preparation relative to reported intention, and an account of what that preparation is.
3. Falsifiability condition: The 'intention sets the cause' reading fails if action initiation is fully determined before and independently of any intention-related process.
4. Variables: measurable / bounded / held open: Measurable: RP timing, reported W time. Held open: whether conscious intention is causal (the free-will question).
5. Test designed: Retrieve Libet 1983 and later reinterpretations.
6. Data (unfiltered): RP precedes reported intention by ~350 ms (Libet 1983); later work models the RP as stochastic accumulation (Schurger et al. 2012) and finds it does not mark conscious intention (2025).
7. Variable Principle applied: Causal status of conscious intention held open; the literature is live.
8. Model update (Capsule: what the failed parts contribute): Intentional action exists and is measurable (accounted); 'cause-setting' by conscious will is plausible, not forced.
9. Documented: This file.
10. Next baseline: Voluntary action measured; causal role of conscious intention open.

## Forcing Test
- Test A (Ground): Measured timing data exist.
- Test B (Uniqueness): Several interpretations survive (unconscious initiation; stochastic accumulation with later commitment).
- Test C (Direction): Direction contested.
- Test D (Falsifiability): Falsifier: a demonstrated action whose initiation is fully predictable from pre-intention activity at the single-trial level would weaken 'cause-setting' by conscious intention.
- **Outcome:** live-hypothesis.

## Anti-Operation (the gap this opens)
Canon writes a three-step progression (reactivity → organization → causation) but gives no observable for the step to 'causation'. Whether this maps onto the measured habitual vs goal-directed distinction is open (not sourced in this run).

## Narrative stripped
Removed: the First → Second → Third Kingdom progression (framework mapping). 'Cause-Setting' in the label presumes conscious causation, which reality does not force; proposed neutral label: 'Voluntary Action / Intention'.
