## Scientific Inquiry run
1. Question (precise): Which organisms show measurable self-recognition, and does that measure self-awareness?
2. What an answer must look like: Mark-test results across taxa, and an argument linking the behaviour to awareness.
3. Falsifiability condition: The factual core fails if no non-human organism shows self-directed behaviour in the mark test and humans do not either.
4. Variables: measurable / bounded / held open: Measurable: mark-test behaviour. Held open: whether behaviour = awareness (the hard problem, held open by canon).
5. Test designed: Retrieve mark-test papers across distant taxa.
6. Data (unfiltered): Chimpanzees (1970), an Asian elephant (2006), cleaner wrasse (2019) pass forms of the mark test. The 2019 authors ask whether passing implies self-awareness.
7. Variable Principle applied: The step from behaviour to experience is held open — as canon holds the hard problem open. Nothing filled.
8. Model update (Capsule: what the failed parts contribute): Behavioural self-recognition: accounted, and taxonomically broad (includes a fish). Experiential self-awareness: unchanged, open.
9. Documented: This file.
10. Next baseline: Self-recognition behaviour measured in mammals and a fish; experience open.

## Forcing Test
- Test A (Ground): Measured for behaviour; not for experience.
- Test B (Uniqueness): Behaviour admits several interpretations (self-awareness vs trained contingency testing).
- Test C (Direction): Consistent: self-recognition follows cognition in the lineages tested, but the fish result suggests it is not late or rare.
- Test D (Falsifiability): The experiential claim has no falsifier from outside the system.
- **Outcome:** proven-open for self-awareness as experience (as canon holds the hard problem); behavioural self-recognition is accounted.

## Anti-Operation (the gap this opens)
Placement: Stage 36 sits between cognition and language, which reads as a human-lineage step; fish mark-test results suggest self-recognition is far older or convergent. Whether the stage is a lineage-specific or repeated transition is open.

## Narrative stripped
Removed: 'Algorithm becomes aware it is running', 'Third Kingdom recognizes itself through First Kingdom substrate', 'Universe builds an organ to observe itself'. Reality neither forces nor contradicts them; no measurement reaches them. The quoted 'I AM' in the label imports the Third Kingdom narrative; proposed neutral label: 'Self-Recognition / Self-Awareness'.
