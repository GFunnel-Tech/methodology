## Scientific Inquiry run
1. Question (precise): Is memory formation implemented by experience-dependent changes in synaptic strength (LTP/LTD)?
2. What an answer must look like: LTP measured; causal manipulation linking LTP/LTD to a behavioural memory.
3. Falsifiability condition: Fails if memories form and persist with synaptic plasticity blocked, or if LTP/LTD manipulation leaves memory unaffected.
4. Variables: measurable / bounded / held open: Measurable: LTP; causal manipulation. Held open: whether synaptic weight change is the sole storage mechanism.
5. Test designed: Retrieve the original LTP paper and a causal test.
6. Data (unfiltered): LTP lasting hours measured (Bliss & Lømo 1973); Nabavi et al. 2014 inactivated/reactivated a memory with LTD/LTP, 'supporting a causal link'.
7. Variable Principle applied: 'Sole mechanism' held open; not filled.
8. Model update (Capsule: what the failed parts contribute): Core consistent; causal support exists but from a single study.
9. Documented: This file.
10. Next baseline: Synaptic plasticity as a supported (not forced) mechanism of memory.

## Forcing Test
- Test A (Ground): Measured.
- Test B (Uniqueness): Not unique: other storage mechanisms are not excluded by the fetched data.
- Test C (Direction): Consistent.
- Test D (Falsifiability): Falsifier in step 3.
- **Outcome:** live-hypothesis (strongly supported).

## Anti-Operation (the gap this opens)
Canon equates memory formation with LTP; the fetched data support LTP/LTD as a mechanism but do not exclude others. Whether to write 'LTP and related plasticity' is open.

## Narrative stripped
Removed: Shepherd’s Way Steps 06–07 mapping. Reality neither forces nor contradicts it.
