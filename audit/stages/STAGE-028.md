**Factual core (graded):** nervous systems arise as tissues specialized for signal processing; they are the first such structure.

## Scientific Inquiry run
1. Question (precise): Are nervous systems the first biological structures whose function is signal processing, and did they arise once?
2. What an answer must look like: Evidence on the phylogenetic origin(s) of neurons and on pre-neural electrical signalling.
3. Falsifiability condition: The 'first' claim fails if dedicated electrical signal processing exists in non-neural systems before nervous systems.
4. Variables: measurable / bounded / held open: Measurable: presence of neurons, bacterial electrical signalling. Bounded: animal origin 833–650 Ma. Held open: single vs multiple origin of neurons; what counts as 'an organ' for early nerve nets.
5. Test designed: Retrieve primary data on ctenophore neural origins, bacterial electrical signalling, animal divergence times.
6. Data (unfiltered): Neural origins unresolved, possible independent ctenophore origin; bacteria conduct long-range electrical signals via ion channels; crown Metazoa 833–650 Ma.
7. Variable Principle applied: Neural-origin count held open (canon does not claim it, so nothing to resolve). 'First processing organ' kept as plausible for a dedicated multicellular organ, not forced.
8. Model update (Capsule: what the failed parts contribute): Nervous systems exist and process signals (accounted). 'First' holds only if 'organ' excludes bacterial and other non-neural signalling.
9. Documented: This file.
10. Next baseline: Nervous systems as specialized signalling tissues; primacy claim conditional on the definition of 'organ'.

## Forcing Test
- Test A (Ground): Measured: nervous systems exist.
- Test B (Uniqueness): Not unique: non-neural electrical processing (bacterial biofilms) exists; neurons may have >1 origin.
- Test C (Direction): Direction: consistent with increasing specialization.
- Test D (Falsifiability): Falsifier: a demonstrated pre-metazoan multicellular tissue dedicated to signal processing would falsify 'first organ'.
- **Outcome:** live-hypothesis for 'first organ whose function is processing'; existence of nervous systems is accounted.

## Anti-Operation (the gap this opens)
If ctenophore neurons evolved independently, canon's single 'Nervous System' stage has the same parallel-origin problem as Stage 25. 'Emergence threshold' has no measured value; a numeric threshold (neurons, synapses, connectivity) is open.

## Narrative stripped
Removed: 'Body builds Second Kingdom organ' and 'Process Density crosses emergence threshold' (framework mappings; no measured threshold exists in the fetched data, so reality neither forces nor contradicts them).
