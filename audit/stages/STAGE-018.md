## Scientific Inquiry run
1. Question (precise): Do mitochondria descend from a proteobacterial endosymbiont; what was the host; how was the symbiont taken up?
2. What an answer must look like: phylogenomic placement of mitochondria and of the host lineage; physiological data on the closest living host relatives.
3. Falsifiability condition: Endosymbiotic origin is falsified if mitochondrial genes place within the host lineage rather than within Proteobacteria. The engulfment mechanism is falsified if the ancestral host is shown to have lacked any capacity for internalization.
4. Variables: measurable: gene sequences, cultured-organism physiology. Derived: phylogenetic placements. Held open: uptake mechanism; timing relative to the GOE (canon's order places it after Stage 17; no date was fetched in this run).
5. Test designed: fetch primary phylogenomic papers for symbiont and host; fetch the first cultured Asgard archaeon.
6. Data (unfiltered): table above. Symbiont: proteobacterial, basal to sampled alphaproteobacteria. Host: Asgard archaea. The cultured Asgard relative is small, syntrophic, protrusion-bearing, with no organelle-like structure; its authors propose entanglement then engulfment as a hypothesis.
7. Variable Principle applied: (a) derived, supported. (b) held open. (c) supported, but canon names only one of the two partners.
8. Model update (Capsule): (a) accounted. Canon's item leaves out the host (an archaeon), which matters to "two organisms become one". (b) "engulfed and not digested" states one mechanism as fact; it is a hypothesis among others (e.g. syntrophic entanglement first).
9. Documented: this file.
10. Next baseline: direct observation of internalization capacity in cultured Asgard archaea, or a dated eukaryogenesis window.

## Forcing Test
- Test A (Ground): (a) grounded in phylogenomics; (b) not grounded.
- Test B (Uniqueness): (a) one candidate survives at the phylum level (Proteobacteria); the exact lineage is unresolved. (b) fails: several uptake scenarios survive.
- Test C (Direction): Forced for (a): the symbiont lineage became the organelle.
- Test D (Falsifiability): Yes (step 3). Falsifier for (b): evidence that the host lineage lacked any means of internalizing a bacterium.
- **Outcome:** live-hypothesis (for the stage as written, which includes the engulfment mechanism). The endosymbiotic origin itself is accounted.

## Anti-Operation (the gap this opens)
Naming the host opens a variable canon does not hold: what the archaeal host was doing before the merger (the cultured relative is syntrophic, not phagocytic). It also opens timing: canon orders Stage 18 after the GOE (Stage 17), but no date for eukaryogenesis was retrieved in this run.
