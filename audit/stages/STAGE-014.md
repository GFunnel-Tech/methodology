## Scientific Inquiry run
1. Question (precise): Does all extant life descend from a single common ancestor, and what is measured about that ancestor?
2. What an answer must look like: a formal test of common vs independent ancestry on universally conserved genes; model-based estimates of the ancestor's age and gene content.
3. Falsifiability condition: A dataset in which independent-ancestry models outperform UCA on universally conserved proteins would falsify it.
4. Variables: measurable: sequence data. Derived: UCA preference, LUCA age, genome content. Held open: LUCA's habitat, whether LUCA was a single lineage or a population, exact age.
5. Test designed: retrieve the formal UCA test and its defence; retrieve the most recent LUCA dating; retrieve a critique of LUCA gene-content inference.
6. Data (unfiltered): table above. UCA strongly preferred. LUCA ~4.2 Ga (4.09–4.33). Genome content estimates are method-dependent (82% of one earlier set rejected by another analysis). Moody et al. infer LUCA was part of an established ecosystem, not isolated.
7. Variable Principle applied: common descent = derived, strongly supported. LUCA's age and content = derived with wide, method-dependent uncertainty. Canon asserts only common descent, which is the supported part.
8. Model update (Capsule): canon's factual core holds. Canon does not state LUCA's age here; the ~4.2 Ga estimate bears on Stage 13's "4 Bya" (see STAGE-013).
9. Documented: this file.
10. Next baseline: LUCA age and gene-content estimates from independent calibration schemes.

## Forcing Test
- Test A (Ground): Grounded in sequence data and formal model selection.
- Test B (Uniqueness): Within the tested model set, one candidate (UCA) survives; independent-ancestry models are rejected even with horizontal transfer allowed.
- Test C (Direction): Forced: descent runs from LUCA to extant lineages.
- Test D (Falsifiability): Yes (see step 3).
- **Outcome:** forced-fill (for common descent only; LUCA's age, habitat and gene content remain open and are not canon's claim at this row).

## Anti-Operation (the gap this opens)
Canon's "single processing architecture" can be read as one organism. Moody et al. infer LUCA lived within an ecosystem of other organisms. Whether "LUCA" names one lineage or a population is open. Also opened: LUCA's inferred age (4.09–4.33 Ga) sits at or before the ~4 Bya canon gives for vent chemiosmosis (row 21), so the order of Stages 13 and 14 is not fixed by data.

## Narrative stripped (if any)
- "Three Kingdoms now coordinate at biological scale" is a framework mapping. Reality neither forces nor contradicts it.
- "Single processing architecture" adds an interpretive frame to "common ancestor". The label itself ("LUCA — Last Universal Common Ancestor") is the standard observational term, so no new label is proposed.
