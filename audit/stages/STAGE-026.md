## Canon says
v5.1 Appendix A, table "Stages 23–49 — ATP Through Recognition To Cycle Restart", row 26:

> **Tissue Differentiation / Gene Expression** — Same DNA, different expression. Second Kingdom directs First Kingdom according to Third Kingdom regulatory context.

**Factual core (graded):** differentiated cell types of one organism carry the same genome and differ by gene expression, set by regulatory context.

**Framework mapping (stripped):** Second Kingdom directs First Kingdom; Third Kingdom regulatory context.

## Scientific Inquiry run
1. Question (precise): Do differentiated cells retain a genome able to specify other cell types, with identity set by expression?
2. What an answer must look like: Experimental reprogramming of a differentiated cell to pluripotency (or nuclear transfer) showing the genome is retained.
3. Falsifiability condition: Fails if differentiation required irreversible loss of genomic information in all somatic lineages.
4. Variables: measurable / bounded / held open: Measurable: reprogramming outcomes. Held open: nothing in the factual core. (Exceptions such as V(D)J recombination in lymphocytes are known genome edits; not fetched in this run, so not graded.)
5. Test designed: Retrieve the primary iPS paper abstract.
6. Data (unfiltered): Takahashi & Yamanaka 2006: fibroblasts reprogrammed by four defined factors; the abstract also states reprogramming by nuclear transfer into oocytes was already known.
7. Variable Principle applied: Nothing held open is filled; the core is measured.
8. Model update (Capsule: what the failed parts contribute): Core integrated as stated.
9. Documented: This file.
10. Next baseline: Same-genome / different-expression is the measured baseline for Stage 26.

## Forcing Test
- Test A (Ground): Measured: reprogramming experiments.
- Test B (Uniqueness): One candidate: identity is carried by expression state, not by loss of DNA (for the lineages tested).
- Test C (Direction): Consistent: differentiation reversible under defined factors.
- Test D (Falsifiability): Falsifier in step 3.
- **Outcome:** forced-fill (factual core).

## Anti-Operation (the gap this opens)
Somatic genome edits (e.g. immune-receptor recombination) and epigenetic memory in reprogrammed cells bound how literally 'same DNA' holds; not sourced in this run — held open.

## Narrative stripped
Removed: the Three Kingdoms mapping (Second directs First under Third). Reality neither forces nor contradicts it; gene-regulatory measurement describes transcription factors and chromatin, not Kingdoms.
