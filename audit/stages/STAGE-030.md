## Scientific Inquiry run
1. Question (precise): Is the action potential all-or-none, and is it the first digital information encoding in biology?
2. What an answer must look like: Measured all-or-none behaviour; evidence of any earlier discrete (digital) biological code.
3. Falsifiability condition: (b) fails if any discrete information code predates neural action potentials.
4. Variables: measurable / bounded / held open: Measurable: all-or-none spiking; genetic-code discreteness. Held open: none needed.
5. Test designed: Retrieve primary data for all-or-none spikes and for the genetic code.
6. Data (unfiltered): All-or-none spikes measured (and even in unicellular Paramecium). The genetic code is a discrete codon→amino-acid mapping, 'virtually universal among extant life forms' (Koonin & Novozhilov 2017); universality across bacteria, archaea and eukaryotes implies (derived) that the discrete code predates animal nervous systems. Hodgkin & Huxley 1952 (PMID 12991237) was located but has no retrievable abstract/full text in this run.
7. Variable Principle applied: Part (a) is measured; part (b) is contradicted by a measured-reproduced observation.
8. Model update (Capsule: what the failed parts contribute): Adjust: keep 'all-or-nothing signal'; replace 'first time biology encodes information digitally' with 'first all-or-none electrical signalling in a nervous system' — or drop 'first'. DNA/RNA sequence already encodes discrete information; unicellular eukaryotes already fire all-or-none spikes.
9. Documented: This file (proposed adjustment for the v5.5 draft; canon is not edited).
10. Next baseline: Action potential = all-or-none electrical signal, not the first discrete code.

## Forcing Test
- Test A (Ground): (a) measured; (b) the ground contradicts it.
- Test B (Uniqueness): For (b), no candidate survives: an earlier discrete code exists.
- Test C (Direction): Direction: the digital genetic code comes first, electrical all-or-none signalling later (and even pre-neural in Paramecium).
- Test D (Falsifiability): Falsifiable and falsified for (b).
- **Outcome:** forced-no for 'first digital encoding'; (a) all-or-none is accounted.

## Anti-Operation (the gap this opens)
What exactly does canon mean by 'digitally'? If it means 'electrical all-or-none', the claim can be narrowed; if 'discrete information', it is contradicted. Also open: whether Stage 30 should be placed as a neural stage when all-or-none spikes exist in single cells.
