## Scientific Inquiry run
1. Question (precise): How long before language did synaptic transmission exist?
2. What an answer must look like: An upper bound on synapse age (animal origin, since chemical synapses are neuronal) and an age for language.
3. Falsifiability condition: (b) fails if synapses are demonstrably younger than ~1 Gyr before language by more than the dating uncertainty.
4. Variables: measurable / bounded / held open: Measurable/derived: crown Metazoa 833–650 Ma; crown Eumetazoa 746–626 Ma; H. sapiens clade ≥ 315 ± 34 ka. Held open: date of language.
5. Test designed: Compute the maximum synapse–language interval: animal origin upper bound minus the youngest plausible language date.
6. Data (unfiltered): Upper bound ≈ 0.83 Gyr (crown Metazoa 833 Ma; language date ≪ 1 Myr in any case). Under the integrated estimate the interval is 0.65–0.83 Gyr if synapses are as old as crown Metazoa, 0.63–0.75 Gyr if they arose with Eumetazoa. Earlier estimates up to 1,298 Ma exist.
7. Variable Principle applied: Language date held open; it does not change the result because any language date is < 1 Myr, negligible against the Gyr scale.
8. Model update (Capsule: what the failed parts contribute): (a) accounted. (b) 'a billion years' exceeds the best current integrated estimate (≤ 0.83 Gyr) but falls within the historical spread of estimates; the contradicting value is a single derived analysis, so no adjustment is forced.
9. Documented: This file.
10. Next baseline: Proposed wording (for the author): 'roughly 0.6–0.8 billion years before language (molecular-clock estimate)'.

## Forcing Test
- Test A (Ground): Derived data exist.
- Test B (Uniqueness): Not unique: the age depends on the calibration strategy (dos Reis et al. report the limit of precision).
- Test C (Direction): Direction: synapses precede language — consistent.
- Test D (Falsifiability): Falsifier: if crown Eumetazoa ages converge below ~0.9 Ga across independent analyses, '~1 Gyr' is ruled out.
- **Outcome:** live-hypothesis for the '~1 Gyr' figure (currently outside the best integrated interval); (a) accounted.

## Anti-Operation (the gap this opens)
The canon figure is a rounded number with no source. Which lineage first had chemical synapses (ctenophore vs cnidarian/bilaterian stem) is unresolved, which also leaves the lower edge of the interval open.

## Narrative stripped
Removed: 'Five-step linguistic chain operating at cellular scale' (framework analogy; reality neither forces nor contradicts it).
