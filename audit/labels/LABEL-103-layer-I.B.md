## Scientific Inquiry run

1. Question (precise): Do the I.B case studies constitute a proof that "the same algorithm that runs a cell runs a city", as the label "Correspondence Proof" asserts?
2. What an answer must look like: Either a deductive derivation, or an empirical test with cases sampled independently of outcome, a comparison group, and a stated effect.
3. Falsifiability condition: The label's "proof" status fails if the evidence set is illustrative (selected to fit) rather than a test that could have come out otherwise.
4. Variables: measurable / bounded / held open: Measurable: each case figure (routed out). Bounded: the five cases are consistent with the pillars as described. Held open: whether pillar adherence predicts infrastructure outcome in general.
5. Test designed: Read the layer; check whether it states a sampling rule, a comparison group, or a derivation.
6. Data (unfiltered): Five cases, one per pillar, each chosen to show failure (or Roman success) under that pillar. No sampling rule, no counter-cases examined, no measure of pillar adherence independent of outcome. Canon's own ◇ files the claim as "Bounded", not proved.
7. Variable Principle applied: A set of cases selected to illustrate a principle is consistent with it but does not prove it. The label fills the "is Correspondence proved at city scale?" variable with "proof". Held open.
8. Model update (Capsule: what the failed parts contribute): The cases remain useful as worked examples. The label narrows to what they are: case studies. The ◇ falsifier (a long-lived system violating all four pillars) remains the live test.
9. Documented: This file. Correspondence: one scale down, the same five-case pattern is used for business departments (Layer V civil-equivalent column); one scale up, 2008 is used at economy scale. Neither scale adds a sampled test.
10. Next baseline: Proposed for v5.5 (not applied): "Civil Infrastructure Case Studies — The Four Pillars at City Scale". Case figures to CLAIM audits. Re-review 2027-09-24.

## Forcing Test

- Test A (Ground): No measurement grounds "proof"; the cases are real events, but their selection is not a test.
- Test B (Uniqueness): Other explanations of each case survive (funding politics, climate, regulation) without the four-pillar mapping; not forced.
- Test C (Direction): The cases point toward the pillars only because they were chosen to.
- Test D (Falsifiability): Canon's ◇ gives a falsifier (a long-lived system violating all four pillars). It has not been searched for systematically.
- **Outcome:** live-hypothesis (falsifier attached in ◇). Not a proof.

## Anti-Operation (the gap this opens)

The pillars have no measure independent of outcome: a failed system is read as having violated a pillar after the fact. The gap: define a pillar-adherence score for infrastructure measured before the outcome (the BEAS of Layer V is the business analogue), so the ◇ falsifier can actually fire.
