## Canon says

v5.1 Layer 0 heading: **"The Base Code — The Universal DNA"**, subtitle *"The irreducible algorithm from which all subsequent layers are gene expressions."*

Subsection **"The DNA Metaphor — Why It Is Exact, Not Approximate"**:

> "DNA is not a description of an organism. It is the base code from which the organism is expressed … The code does not change between expressions. The cell type changes. The tissue changes. The organ changes. The organism changes. The code is invariant across all of them."
>
> "The Universal Algorithm operates identically. … Per Correspondence: the code must be identical at every scale because reality is self-similar at every scale. This is law, not analogy. Layer 0 is the codon. Every layer that follows is a protein."

The factual core the label carries: (a) the DNA of an organism is invariant across all its cell types; (b) the correspondence between DNA and the three-step loop is exact, not approximate.

## Scientific Inquiry run

1. Question (precise): Is the DNA of a multicellular organism invariant across all its cells ("The code is invariant across all of them"), and is the DNA → Layer 0 correspondence therefore "exact, not approximate"?
2. What an answer must look like: A measured statement of whether somatic cells carry the germline sequence unchanged, with a rate or a documented mechanism of change.
3. Falsifiability condition: The "exact invariance" claim is falsified by any reproduced mechanism that changes the DNA sequence of somatic cells within one organism.
4. Variables: measurable / bounded / held open: Measurable: somatic recombination (V(D)J) in lymphocytes; somatic mutation rate per bp per mitosis. Bounded: invariance holds approximately (order 1e-9 per bp per mitosis in fibroblasts). Held open: whether "the base code" of the framework has any measured relation to DNA at all.
5. Test designed: Fetch primary records on programmed somatic DNA rearrangement and on measured somatic mutation rates; compare with canon's invariance statement.
6. Data (unfiltered): Table above. Lymphocytes assemble new genes by recombining germline segments and add somatic mutations (Tonegawa 1983). Human fibroblasts accumulate 2.66e-9 mutations per bp per mitosis, about two orders of magnitude above the germline rate (Milholland et al. 2017).
7. Variable Principle applied: DNA invariance across cells is an approximation, not an exact identity: it fails by design in lymphocytes and by a measured rate elsewhere. The claim "exact, not approximate" is ruled out. The separate question of whether the three-step loop resembles DNA at all is held open (no measurement).
8. Model update (Capsule: what the failed parts contribute): The failed claim gives the precise form of the analogy: DNA is a mostly-conserved template with measured, sometimes programmed, change. If the analogy is kept, it now carries a measured error term, which is a closer fit to the framework's own "base code holds until reality contradicts it" (substrate item 7) than "never changes".
9. Documented: This file. Correspondence: one scale down, codon → amino acid mapping (the genetic code) is itself near-universal but has known variants; not fetched in this run, held open. One scale up, the framework's layers are texts, not molecules; "Layer 0 is the codon … every layer is a protein" is a metaphor at that scale.
10. Next baseline: Proposed for v5.5 (not applied to canon): re-label Layer 0 "The Base Loop — DETECT → PROCESS → RESPOND" and retitle the subsection "The DNA Analogy — Where It Holds and Where It Breaks". Old name kept in lineage.

## Forcing Test

- Test A (Ground): Grounded. Somatic DNA change is a reproduced measurement (V(D)J recombination; measured somatic mutation rates).
- Test B (Uniqueness): For the claim "DNA is invariant across all cells, exactly", measurement leaves zero surviving candidates: invariance is approximate.
- Test C (Direction): Measurement points one way: toward "mostly conserved, with measured and programmed change", away from "exact".
- Test D (Falsifiability): The claim had a clear falsifier (a reproduced somatic DNA change). The falsifier fired.
- **Outcome:** forced-no for "exact, not approximate". The Layer 0 loop itself (DETECT → PROCESS → RESPOND) is not graded here; it is canon's base code and is not altered.

## Anti-Operation (the gap this opens)

If the DNA analogy carries an error term, what is the base loop's error term? Canon states no measured rate at which a system fails to run DETECT → PROCESS → RESPOND, or a case where the three steps are not separable. The gap: define, for the base loop, what a "somatic mutation" would be (a run where the loop's output does not become the next input), and whether it can be observed.

## Narrative stripped (if any)

- "The Universal DNA": DNA is a specific molecule (deoxyribonucleic acid). Calling an abstract three-step loop "DNA" is a metaphor; reality does not force it. The observation-based name keeps what the layer contains: the loop itself.
- "Exact, not approximate" / "This is law, not analogy": ruled out for the DNA half (above); unmeasured for the loop half.
- "Per Correspondence: the code must be identical at every scale because reality is self-similar at every scale": a Layer II mapping (see LABEL-109). Reality neither forces nor contradicts it by any measurement fetched here.
- "gene expressions" (subtitle): same metaphor; kept in lineage, not in the proposed name.
- Nothing is renamed in canon. `versions/v5.1/` is immutable; the old name stays in the lineage.
