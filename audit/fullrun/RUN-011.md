## Canon says

**The algorithm** (v5.1 Algorithm Index, Layer III+). *Use when: building anything that should compound knowledge, learning, or capability over time rather than starting from scratch each cycle.*

> 1. Map the prior paths. What has been attempted before in this domain, including failures?
> 2. Extract the integration data from each path. What did each prior path contribute as information?
> 3. Build current substrate to load all prior path data. Documentation, institutional memory, codified learning, retained team experience.
> 4. Begin new exploration from the integrated substrate. New paths begin with all prior path information available.
> 5. Test for the phi ratio. Is the integration ratio of meaningful path data to total possibility space approximating 1.618? Below: still searching. At: stable. Above: rigid.
> 6. Maintain the ratio by continuing to integrate new paths while continuing to allow new exploration.
> 7. Per the Golden Ratio of Purpose: identify where most-selfish creative desire converges with most-selfless creative desire. The convergence point is the structural attractor for sustained integration.

**The layer.** *"density is not only a count of operations per unit substrate, but a count of integrated paths per unit substrate."* Restated threshold: *"A system reaches the emergence threshold when its current configuration integrates enough prior path information that further exploration is constrained productively. Below the threshold, exploration is naive — most paths fail with full information cost. Above the threshold, exploration is informed … This is why expertise compounds. Why immune memory accelerates response to repeat infections."*

*"The Golden Ratio of Purpose described in Layer III is the integration ratio of meaningful path data to total possibility space. Systems operating at this ratio are stable. Systems operating below it are still searching. Systems operating above it have over-integrated and become rigid."*

Canon's own held-open variable at this layer: *"Whether the phi ratio is mathematically necessary or merely empirically observed across natural integration systems — held open."*

**Split (RUNBOOK rule 4).** *Factual cores graded here:* that a system can hold prior-path information in its substrate and begin new exploration from it (steps 1-4); that the ratio of meaningful path data to total possibility space can approximate 1.618 (step 5). *Framework mappings not graded:* Yin/Yang, Kingdoms, the cosmological row of the Application table, "structural attractor".

## Algorithm run (literal, step by step) — target: a bacterial cell (*E. coli* K-12)

1. **Map the prior paths — "what has been attempted before in this domain, including failures?"** *Produced:* for a bacterial lineage the prior paths are prior encounters, and they are measurable: phage and plasmid DNA that entered the cell, and the chromosomal breaks that came with it. Step completed with measured content.
2. **Extract the integration data from each path.** *Produced:* the measured extraction is a spacer — a fragment of the foreign sequence, selected by the acquisition machinery with a measured bias (primed adaptation follows a partially matching spacer; prespacer selection is depleted for candidates containing the consensus PAM AAG). Step completed.
3. **Build current substrate to load all prior path data.** *Produced:* the chromosomal CRISPR array **is** that substrate, and it is heritable. Step completed — and it is the one place where canon's wording maps onto a measured molecular structure rather than an analogy. *But:* the step says "load **all** prior path data", and measurement contradicts "all": in up to 4% of conjugation events the incoming DNA is not integrated but **fully degraded by RecBCD**, and wild-type spacer acquisition is actively biased *against* the host's own sequence. Integration is measured selective; canon's step is stated exhaustive. This is the same defect F-067 found in Layer I.G's "nothing is discarded".
4. **Begin new exploration from the integrated substrate.** *Produced:* confirmed — primed adaptation is exactly this: a stale spacer that no longer protects still directs acquisition to the right target, so the next round starts from the last round's information. Step completed with measured content.
5. **Test for the phi ratio — "is the integration ratio of meaningful path data to total possibility space approximating 1.618?"** `BLOCKED: the quantity canon names cannot take the value canon names.` A ratio of *a part* (meaningful path data) to *the whole it is part of* (total possibility space) lies in [0, 1] by construction; 1.618 is greater than 1, so no system — bacterial or otherwise — can exhibit canon's ratio at canon's value. Run with the only computable denominator available for a bacterium, the arithmetic is not close: a 4,639,221 bp genome has 4^4,639,221 ≈ 10^2,793,089 possible sequences, and the integrated record (a CRISPR array of tens of spacers, plus whatever recombination has fixed) is a vanishing fraction of it. The ratio is measured-adjacent and it is ~0, not 1.618 — and it would be ~0 for every organism that has ever lived, which means the "Below / At / Above" branches in step 5 and the Application table cannot be reached by any real system on the stated quantity. `BLOCKED: value withheld under audit/prediction/PROTOCOL.md (PRED-001 sealed)` for the one alternative reading — a φ-valued *allocation* of the cell's own substance rather than a path-to-possibility ratio. That reading is what PRED-001 sealed; it is not tested here and no value is fetched, estimated or implied.
6. **Maintain the ratio.** `BLOCKED: no ratio exists to maintain (step 5).`
7. **"Per the Golden Ratio of Purpose: identify where most-selfish creative desire converges with most-selfless creative desire."** `BLOCKED: the step requires desires. No measurement attributes a creative desire to E. coli.` `not-applicable` for this system, and per SCHEMA §3b that is recorded as a failure of canon's universality claim — Layer III+ asserts its threshold governs personal, business, civilizational **and** cosmological systems and cites **immune memory** as an instance, so a bacterium is inside its stated scope while the algorithm's final step is not defined for one.

## Scientific Inquiry run

1. Question (precise): Run against a bacterial cell, does the Integration Density Algorithm produce a correct, non-trivial statement that measurement confirms and that the layer's structure supplied — and can step 5's phi test be evaluated for any real system?
2. What an answer must look like: for steps 1-4, a measured bacterial structure that holds prior-path information heritably and demonstrably conditions later exploration; for step 5, a unit for "meaningful path data", an enumeration of "total possibility space", and a value to compare with 1.618.
3. Falsifiability condition: the `works-descriptive` grade for steps 1-4 fails if measurement had shown no heritable record of prior encounters conditioning later behaviour — a bacterium whose response to a second phage exposure is indistinguishable from the first would have falsified it, and CRISPR primed adaptation is the measurement that confirms it. The `forced-no` on step 5 fails only if canon redefines the ratio so its numerator is not part of its denominator.
4. Variables: measurable / bounded / held open: **Measurable** — spacer acquisition and its biases, primed adaptation, recombination frequency (up to 96%), RecBCD degradation of the remainder, ~1 crossover per generation, genome length. **Bounded** — the integration ratio on the only computable denominator: between 0 and ~10⁻²⁷⁹³⁰⁰⁰, hence bounded far below 1. **Held open** — canon's units for path data and possibility space; whether φ is necessary or merely observed (canon's own ◈, not resolved here); any φ-valued allocation (sealed).
5. Test designed: execute steps 1-7 literally; for steps 1-4 identify the measured bacterial structure that plays each role; for step 5 attempt the arithmetic with a real denominator; for step 7 check whether the target can satisfy the step's precondition.
6. Data (unfiltered): the table above. Steps 1-4 completed and each has measured content, with one contradiction inside step 3 ("load **all**" versus measured selective degradation and anti-self bias). Step 5 is blocked by an internal impossibility, not by missing data. Steps 6-7 inherit the block; step 7 is `not-applicable`.
7. Variable Principle applied: canon's held-open variable on whether φ is necessary or observed is **left open** — this run does not resolve it, and the `forced-no` is narrower than that variable: it rules out only that canon's *stated quantity* can equal 1.618, which is arithmetic, not a judgement about φ in nature. The units for "meaningful path data" stay held open rather than being supplied by the audit. The sealed allocation stays sealed; the run states what it cannot test and why.
8. Model update (Capsule: what the failed parts contribute): three repairs, in order of cost. (i) Step 5's quantity must be restated. Either the ratio is *part : remainder* (in which case the φ value is 0.618 : 0.382, a division, and "approximating 1.618" is the ratio of the two parts, not of part to whole) or canon means something else entirely; as written it is unattainable. This is a one-line fix with real consequences, because PRED-001 had to make that repair on canon's behalf before it could seal a testable prediction at all. (ii) Step 3's "all prior path data" must become "the data the system selects", since measured integration is selective and measured non-integration is destructive. (iii) Step 7 must be restated in terms a system without desires can satisfy, or the layer must state that its scope is narrower than the four rows of its own Application table.
9. Documented: this file. Correspondence: one scale down, the same "load all / discard nothing" defect is recorded at Layer I.G by F-067 and CLAIM-021, from independent measurements — two layers assert exhaustive retention and the same bacterium refutes both; one scale up, Layer III+ inherits Layer III's missing threshold, so [`RUN-010.md`](RUN-010.md)'s step-3 blocker and this file's step-5 blocker are the same hole seen twice. Cross-references: F-067, F-077, [`../claims/CLAIM-003.md`](../claims/CLAIM-003.md).
10. Next baseline: a restatement of step 5's quantity with a unit, plus canon's decision on selective versus exhaustive integration. After that, PRED-001's Phase B is the test that matters. Re-review 2027-09-24.

## Forcing Test

- Test A (Ground): Grounded for steps 1-4 — every role in them has a measured bacterial occupant. Ungrounded for step 5 onward.
- Test B (Uniqueness): Steps 1-4 are not unique to canon: "keep a record of past encounters and use it next time" is what adaptive immunity means, and canon's own text cites immune memory as its example, so confirming the layer on CRISPR is close to definitional (the same defect F-064 found for DETECT → PROCESS → RESPOND on signal transduction). Step 5's φ is unique to canon and is ruled out as stated.
- Test C (Direction): Measured and signed: remove the integrated record (naive spacer array, or recBCD mutants that lose self-discrimination) and later exploration changes measurably. The direction canon asserts — integration improves later hit rates — is confirmed in this system.
- Test D (Falsifiability): Steps 1-4: yes, falsifiable, and confirmed. Step 5: not falsifiable by measurement, because it is ruled out by arithmetic before any measurement is taken. Step 7: not falsifiable for this system.
- **Outcome:** `forced-no` for the claim that a real system's ratio of meaningful path data to total possibility space approximates 1.618 — ruled out by the definition of the quantity, for every system, not just bacteria. Steps 1-4 stand as a correct description whose content is supplied by the biology, not by the layer. Canon's own ◈ on whether φ is necessary or observed remains **open** and is untouched by this result.

## Anti-Operation (the gap this opens)

Four gaps. (i) If step 5 is repaired to a part-to-remainder division, the layer acquires its first testable content — and the test already exists and is sealed ([PRED-001](../prediction/PROTOCOL.md)), which means this run cannot know whether the repair helps canon or sinks it. The audit has deliberately put its sharpest question out of its own reach. (ii) A `forced-no` on a stated value, with the underlying variable left open, is a state the audit schema handles awkwardly: the file grades one claim, and here the narrow claim is closed while the wide one must stay open. (iii) Steps 1-4 working on CRISPR is evidence of the same kind as F-064's: the layer was built from immune memory and then confirmed on immune memory. Canon has no rule for how much a confirmation counts when the instance is the instance the claim was abstracted from. (iv) The selective-integration finding makes two canonical layers (I.G and III+) assert exhaustive retention that one organism refutes; canon nowhere reconciles them, which is F-068's problem in a second location.
