## How to run an algorithm (the invariant form)

1. Identify which algorithm to run (use the [Algorithm Index](algorithms.md), or the Master Meta-Algorithm if the domain is not pre-specified).
2. Execute the numbered steps **in order**. Do not skip; do not invert.
3. If a step cannot be completed, **stop** — the blocker is the location of the work.
4. **Document the run.** Per Layer VI Step 6: if it isn't written, it doesn't exist as a process.
5. After completion, note what worked, what deviated, and what to integrate (Layer I.G).
