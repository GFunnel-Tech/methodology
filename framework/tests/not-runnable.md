# Tests That Cannot Be Run As Written

Recording these is the point of the Capsule (Layer I.G): a test that cannot be run is information about the test, and it is not lost.

## §14 item 2 — the meson 1/3 test

**v5.4 §6 states:** *"Projection rule: line value 2/3 invariant; 2/9 = 2/3 read per three-fold partition; 1/3 for two-fold. Test proposed: mesons (two strands) should read 1/3 where baryons read 2/9. Not run."*

**Not runnable.** No observable is specified. For the lepton case the rule was concrete — δ in the Brannen parametrization of three masses. For mesons, the text does not say *what quantity* should equal 1/3: not a Koide-type ratio over which meson masses, not a mixing angle, not a decay parameter. "Baryons read 2/9" is also unestablished — §6's 2/9 result is about charged **leptons**, not baryons.

**To make it runnable, canon must state:** (a) the specific meson multiplet, (b) the dimensionless quantity computed from their masses, and (c) the numerical value predicted, before it is computed. Until then the test has no content to check.

Note also §6's own cross-domain guard: 2/9 shows "clean near-hits only in generation-1↔2 quark mixing… 1% off, 2.6σ from 2/9." That is the *existing* evidence in the quark sector, and it is already described as "consistency in one sector, not convergence."

## §14 item 4 — resolve strand ≠ generation

**Held open, deliberately.** v5.4 demoted the partition identity to a **stipulation** in-run (§6, retraction #11) because generations are excitations, not spatial strands. Closing it requires either the tension law (Gap 2's single missing input) or a genuinely three-fold lepton partition that has not been found.

Supplying one here would be filling a held-open variable with assumption — the one act [`../../AGENTS.md`](../../AGENTS.md) calls "the single most important rule" to avoid. It stays open.
