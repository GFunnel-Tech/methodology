Each domain is not an illustration; it is a **test**. Per the Variable Principle: if any domain resists the mapping cleanly, it becomes a *named variable*, not a disproof.

## Using a domain

To apply the framework to a domain **not** explicitly named here, do not improvise — run the **Master Meta-Algorithm** and label the result a *derivation*:

1. Name precisely what you are operating on.
2. Locate it in the Three Kingdoms (First / Second / Third).
3. Identify which of the ten domains above it belongs to.
4. Identify the most operative Hermetic principle.
5. Run the Master Meta-Algorithm against the domain; the specific algorithm emerges by structural derivation.
6. Document the derived algorithm — it becomes substrate for future iterations.
