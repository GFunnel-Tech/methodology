# The Gap Register

v5.4 reports results by **gap number** — "Gap 1, final state" (§2), "Gap 2" (§6), "Gap 3" (§5), "Gap 5" (§5). The numbering originates in the **Forcing-Test Audit Paper**, which is *not in this repository*; but **§4a.5 lists the gaps in frequency form**, and that table is the closest thing to a definitive list inside canon. This register merges the two: each gap as §4a.5 names it, with the section that addresses it.

It adds no claim: every status line below is quoted or directly paraphrased from v5.4 — chiefly §4a.5.

> **This is a navigation aid, not canon.** Where it and a version document differ, the version document wins. If the Forcing-Test Audit Paper is added to `versions/` or a `substrate/` directory, this file should be replaced by a link to its actual gap list.

## W1 — the other undefined symbol, now defined

v5.4 §8 names **W1** as one of D3's two locks without defining it. §4a.5 supplies the definition:

> **W1 · Negative energy** — *a sustained **deficit** of frequencies relative to the node* (the Casimir effect does this between plates); negative-frequency modes = the anti-container = the line run backward. Container/Anti-Container = positive/negative frequency; the self-dual center = light, E = pc, its own antiparticle.

**Status: live route.** This converts W1 from an unexplained label into a stated physical handle. It does not make W1 achievable — sustained, macroscopic negative energy density remains bounded by the quantum energy inequalities (Ford–Roman, credited in §10).
