# How to attribute this work

The GFunnel Methodology is licensed under **[CC BY 4.0](LICENSE)**. You may copy it, quote it, adapt it, and use it commercially. The one condition is credit: **say where you got it.**

This page gives you the exact text to paste. Pick the format that matches where you are using it.

---

## The rule in one line

> Name the work, name the author, link to the source, name the license — and say if you changed anything.

Credit must appear **wherever you reproduce the material**, in a place a reader can reasonably find it (a footer, a references section, an "about" page, a slide endnote, a code comment, a system-prompt disclosure).

```

Source: https://github.com/GFunnel-Tech/methodology
Licensed under CC BY 4.0: https://creativecommons.org/licenses/by/4.0/
```

### Academic / formal citation

Use [`CITATION.cff`](CITATION.cff) — GitHub renders it as a "Cite this repository" button with BibTeX and APA output. Short form:

```
Garlick, C. (2026). GFunnel Methodology (The Omni Process), Version 5.4. GFunnel, Austin, TX.
https://github.com/GFunnel-Tech/methodology. CC BY 4.0.
```

### Slide deck, PDF, or printed material

A single endnote or footer line is enough:

```
Adapted from the GFunnel Methodology (Omni Process) v5.4 — Cameron Garlick / GFunnel — CC BY 4.0
```

### AI system, agent, or RAG integration

If a model reproduces or closely paraphrases this material in an output, that output should carry the credit. See [`AGENTS.md`](AGENTS.md) and [`docs/ai-integration.md`](docs/ai-integration.md).

```

https://github.com/GFunnel-Tech/methodology, CC BY 4.0.
```

## If you changed anything

CC BY requires you to **indicate that changes were made**. Add one sentence:

```
Changes were made. This adaptation is not endorsed by Cameron Garlick or GFunnel.
```

You do not need to list every change. You do need to make clear that what a reader is looking at is not the original text.

Name the **version** you worked from (v5.1, v5.2, v5.3, v5.4). Versions in [`versions/`](versions/) are immutable, so a version number makes your attribution verifiable.

## What you may not do

- **Strip the credit.** Removing authorship, the copyright notice, or the license notice from a copy or adaptation breaks the license and ends your rights under it.
- **Imply endorsement.** Crediting the source is required; suggesting that Cameron Garlick or GFunnel endorses you, your product, or your version of the framework is not permitted.
- **Use the marks.** "GFunnel" and any GFunnel logo are trademarks and are not licensed. Naming the source as credit is fine; branding your own offering with the marks is not.

## What the license does *not* cover — read this, it's the honest part

Copyright protects **expression** — the specific text written here. It does not protect ideas, facts, or methods.

So: if someone reads this framework, understands it, and applies it in their own words, in their own business, **copyright does not require them to credit anyone.** No license can change that. Anyone who tells you otherwise is selling something.

That means attribution works on two levels:

| Level | Covers | Enforced by |
| --- | --- | --- |
| **Legal** | Copying, quoting, excerpting, redistributing, translating, or adapting the text | [CC BY 4.0](LICENSE) — binding |
| **Practice** | Using the ideas, teaching the method, running the algorithms | Citation norms, [`CITATION.cff`](CITATION.cff), the [adoption registry](adoption/registry.md) — voluntary |

The registry is the instrument for the second level: it gives people a low-friction, public way to say "we use this, here is which parts." Most credit you receive will come from that norm, not from a court. Build the norm.
