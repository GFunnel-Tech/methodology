# Glossary (Quick Reference)

A short orientation glossary of the most load-bearing terms. The **complete** glossary is in the canonical text: [v5.1 → Glossary of Framework Terms](../versions/v5.1/GFunnel-Methodology-v5.1.md#glossary-of-framework-terms).

| Term | Short definition |
| --- | --- |
| **Omni Process** | The universal algorithm claimed to operate at every scale of reality: `DETECT → PROCESS → RESPOND`. The methodology's subject. |
| **Base code** | The irreducible three-operation algorithm (Layer 0). Invariant across all expressions; only the substrate changes. |
| **The Three Kingdoms** | **First** (matter/execution), **Second** (organization/system), **Third** (consciousness/intent). Output quality is determined by which Kingdom the system operates from. Third is foundation, not apex (per Mentalism). |
| **The Variable Principle** | The governing epistemology: name unmeasured quantities as variables and hold them open; never fill a variable with assumption. |
| **Held-open variable** | A quantity the framework explicitly refuses to resolve without measurement. An honest bound, not a gap. |
| **Correspondence** | The Hermetic principle that the same algorithm operates at every scale — "as above, so below." Treated as law, not analogy. |
| **The Dynamic Middle (Zhongyong)** | The continuously recalibrating center between the Yang extreme (overextension) and the Yin extreme (paralysis/numbing). Not a fixed point. |
| **The Capsule (Slime Mold Integration)** | Layer I.G: every path explored is integrated; inefficient paths redistribute their information. Nothing is lost. The reason the framework iterates rather than restarts. |
| **The Seven Hermetic Principles** | Mentalism, Correspondence, Vibration, Polarity, Rhythm, Cause-and-Effect, Gender — the convergence set the framework maps onto. |
| **BEAS** | The scoring instrument in Layer V (Garlick Equilibrium): 9 departments × 4 pillars + coordination scores. A diagnostic, not a false-precision metric. |
| **The Four Pillars** | Correctness, Complexity, Patience, Resilience — the constitutive requirements at every scale (cell to civilization). |
| **The Five Modes** | Direct Teaching → Demonstration → Documentation → System-Building → Cultural Embedding: how a process outlasts its vessel (Layer IV). |
| **Forced vs. Guided** | Whether a mechanism is experienced as a prison (guidance refused) or communion (guidance received). "Forced" is the residue of refused guidance. |
| **Scaffolding vs. Constitutive** | Scaffolding: provisional forms, outgrown by internalization. Constitutive: the laws that make a mechanism itself; broken only into noise/dissolution. |
| **The Forcing Test** | The Meta-Tier classifier (v5.3): Ground / Uniqueness / Direction / Falsifiability → forced-fill · live hypothesis · stipulation · proven-open. |
| **The Container (Layer ⊙)** | The meta-tier (v5.3): the framework run against itself, made architectural. Contains the Forcing Test, the Anti-Operation, ◇, and the synthesis loop. |
| **Proven-open** | A gap that structurally cannot be closed from inside the system (borders the Gödel ground). Named, not sealed. |
| **Line-Field (v5.4)** | A dense network of *relations* (not strings), visible the way filings reveal magnetic field lines; every knot sits on lines running through its history and across to what it has interacted with. Lines are geodesics at First Kingdom scale. *(Geodesic identity: forced at First Kingdom scale. Lines as **physical** objects: live hypothesis — see ledger #9.)* |
| **Knot-Line (v5.4)** | A line that bends, stretches, carries ripples; ripples converge and knot without the ends touching. A knot is a field configuration, not an object with parts. *(Knots-as-particles: live hypothesis; Skyrme correspondence partial.)* |
| **Lamina (v5.4)** | The origami: layers formed as knots stack and fold; each fold adds density. Begins at the first stack of knots. Not laminar flow. *(Live hypothesis; falsifier attached — nuclear saturation as fold plateau — and not yet run, ledger #13.)* |
| **The Loop (v5.4)** | Motion *is* tying and untying: ripples converge → knot → summed interactions reach its specific point → it unties → its ripple shakes the next. Self-sustaining after the first reflection (Stage 1→2). *(Mechanism forced, ledger #8; the **first** boundary is proven-open.)* |
| **The Specific Point (v5.4)** | A knot persists until the superposition reaches the specific configuration that unties it; energy sets access, geometry sets the point; lifetime = overlap. *(Forced, ledger #10. Whether "exact" conservation means **no** such point or merely a very high one is **held open** — do not state either as settled.)* |
| **Threshold classes (v5.4)** | *None* (always coupled, only falloff), *present* (activation), *never-reached* (decoupled); height set by the pair and shifted by surrounding line density; lowered by mediation; raised by layer gating. *(Derivation inside v5.4; no separate Iteration Ledger row — status not yet classified.)* |

> **v5.4 terms** are tagged with their Forcing Test status because, unlike the entries above them, they assert structure rather than define vocabulary. The canonical v5.4 text is **not yet in this repository** (see [`../versions/LATEST.md`](../versions/LATEST.md)); until it lands, treat these entries as pointers to a proposal, not to canon.

> When an AI system uses a term, it should preserve these distinctions — especially **measured vs. derived vs. held-open** and **Scaffolding vs. Constitutive**. See [`../AGENTS.md`](../AGENTS.md).
